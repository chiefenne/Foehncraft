- **Shared install on Linux.** `tools/install-shared.sh` installs a release (or, with `--build`, a source build) once for all users under `/opt/Foehncraft/<version>/`, with a Python virtual environment per version (gmsh, numpy, matplotlib, h5py; or the distribution's packages with `--python system`, never pip into the system Python), `env.sh`/`env.csh`, a module file for Environment Modules and Lmod, and the `current` default. Several versions stay side by side: users switch with `foehncraft-use 1.1.0` or `module load foehncraft/1.1.0`, the administrator moves the default with `--activate`. `--install-rust` puts a system-wide Rust under `/opt/Foehncraft/rust` for source builds, `--native` tunes them to the CPU. The install guide has the new section "Shared install on Linux", with a complete source build for Debian 13, and three more first-build problems (PEP 668 `externally-managed-environment`, Rust installed as root, `GLIBC not found`).
- **Linux release programs on older systems.** The Linux release build now runs in the manylinux_2_28 container and checks the glibc floor: the programs run on glibc 2.28 or newer (RHEL, Rocky and Alma 8 and 9, Debian 11 to 13, Ubuntu 20.04 and newer) instead of 2.39.
