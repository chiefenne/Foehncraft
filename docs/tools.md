# Tools

Generated by `foehn commands --markdown` from the tool registry (D196, crate `foehncraft-tools`); do not edit by hand. Every function of the engine is a tool with a stable id, a contract version, typed input and output and an action kind (D198): `read` reads and computes, `write-files` writes files, `start-run` starts a run. The command line, the Python package and the MCP server reach the same tools. `foehn commands` prints this catalogue as JSON (`foehn.tool-catalogue`) with the full input and output schemas; `foehn call <id> --input file.json` runs a tool and prints the result envelope (`foehn.tool-result`, see [interfaces.md](interfaces.md#tool-registry-d196)).

## `case.check`

Check a flow case: validation, boundary conditions on the first mesh and the cost estimate (D78, D81).

Category `case`, action `read`, version 1.

### Input

| Field | Type | Default | Description |
|---|---|---|---|
| `case` | string | required | Flow case file (TOML). |
| `set` | array of string | `[]` | Case keys to override, `key=value` with a TOML value, in order (D62). |
| `out` | string | – | Output directory (overrides `output.directory`). |
| `threads` | integer | – | CPU threads (overrides `run.threads`). |
| `levels` | array of integer | – | Refinement levels of `[mesh.generate]` (overrides `verification.levels`). |
| `max_iterations` | integer | – | Largest number of outer iterations (overrides `solver.max_iterations`). |
| `no_vtkhdf` | boolean | `false` | Do not write the VTKHDF file. |
| `restart` | string | – | Restart file, or `latest` (overrides `run.restart`). |
| `end_time` | number | – | End time of a transient case in s (replaces `time.end_time` and `time.steps`). |
| `backend` | string | – | Where the flow loop runs: cpu or cuda (overrides `run.backend`). |
| `ptx` | string | – | PTX module of the cuda backend (overrides `run.ptx`). |

### Output
