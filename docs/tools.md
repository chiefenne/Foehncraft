# Tools

Generated by `foehn commands --markdown` from the tool registry (D196, crate `foehncraft-tools`); do not edit by hand. Every function of the engine is a tool with a stable id, a contract version, typed input and output and an action kind (D198): `read` reads and computes, `write-files` writes files, `start-run` starts a run. The command line, the Python package and the MCP server reach the same tools. `foehn commands` prints this catalogue as JSON (`foehn.tool-catalogue`) with the full input and output schemas; `foehn call <id> --input file.json` runs a tool and prints the result envelope (`foehn.tool-result`, see [interfaces.md](interfaces.md#tool-registry-d196)).
