Generated by `foehn schema --markdown` from the structs that read the case file (D77); do not edit by hand. Units are SI (D44). *Run time*: the key may change during a run, by re-reading the case file (D40). `<name>` is a boundary name, `[]` an array of tables. The JSON Schema itself: `foehn schema`.
